Import GROBID Training Data

Upload a ZIP with the PDFs, the training annotations (*.training.<model>.tei.xml) and their raw feature files (*.training.<model>), in any folder layout. Annotations become gold files, or versions if the document has a gold file of that variant. Documents without a PDF, or whose PDF differs from the one in the collection, are skipped.
The GROBID processing flavor the training data belongs to.
The GROBID revision the feature files were computed with, if known (e.g. a commit hash).
